# Email Assistant

**Planned — no implementation yet.**

A phone-focused app to summarize emails and help figure out which ones need a response.

## First version

- Connect one email provider with read-only access.
- Show short summaries and explain why a message needs attention.
- Let the user correct the priority of a message.

Calendar integration and support for more providers can come later. The first step is getting a small inbox view working and deciding how to handle credentials and AI requests.
